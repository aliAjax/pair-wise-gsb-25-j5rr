# hxwl-11 眼科弱视遮盖训练台账

在验光页基础上扩展的弱视遮盖治疗台账：把家长口头报的遮盖时长变成可复核的门诊记录。

## 功能

- **遮盖记录录入**：患儿按左右眼登记矫正视力、每日遮盖分钟、本周训练次数；同一天同一眼仅保存一次（重复保存自动覆盖并提示）
- **医生确认**：遮盖分钟超出确认区间（默认不足 30 分钟或超过 360 分钟）的记录先进入「待确认」，医生确认后才计入本周完成率，驳回则不计入
- **本周完成率**：按患儿/眼别对照治疗方案（每日分钟 × 每周天数）计算，待确认记录不计入；附周一至周日状态条
- **方案调整留痕**：调整每日遮盖分钟/每周天数必须填写原因，旧值与新值一并存入调整记录
- **各自维护**：患儿资料、确认条件（上下限分钟）、界面分区独立维护
- **本地留档**：患儿资料、遮盖记录、治疗方案、调整记录、确认条件分别存放在独立的 localStorage 键（`hxwl11.occlusion.*`），关闭页面再打开仍能看到周进度和调整记录

## 技术栈

React + Vite + TypeScript + CSS
