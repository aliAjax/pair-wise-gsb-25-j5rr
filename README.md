# hxwl-11 弱视遮盖训练台账

眼科弱视门诊遮盖治疗依从性管理：按左右眼记录矫正视力、每日遮盖分钟与本周训练次数，
异常时长留待医生确认后计入完成率，方案调整写明原因并保留旧值。

## 技术栈

React + Vite + TypeScript + CSS（纯前端，数据存本机）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 功能

- **训练台账**：按日期 + 左/右眼记录矫正视力、每日遮盖分钟、本周训练次数；同一天同一眼只保存一次，重复保存为覆盖。
- **待医生确认**：每日遮盖不足 30 分钟或超过 6 小时的记录自动置为「待确认」，医生确认通过后才计入本周完成率，驳回则不计入。
- **周进度**：本周遮盖完成率（计入分钟 ÷ 每日目标 × 7）、已计入天数、最新自报训练次数、矫正视力序列，关闭页面再打开仍在。
- **方案调整**：调整遮盖眼 / 每日分钟 / 每周次数必须填写原因，旧值与原因永久保留在调整时间线中。
- **本地留档**：localStorage 独立存储（`src/services/localArchive.ts`），支持导出 JSON、清空并恢复演示数据。

## 模块划分（各自维护）

| 模块 | 文件 | 说明 |
| --- | --- | --- |
| 患儿资料 | `src/data/patients.ts` | 初始患儿档案（资料与台账、规则解耦） |
| 确认条件 | `src/config/confirmationRules.ts` | 30 分钟 / 6 小时阈值与计入判定，改条件只动这里 |
| 本地留档 | `src/services/localArchive.ts` | localStorage 读写、演示数据、导出 |
| 周统计 | `src/utils/stats.ts` / `src/utils/week.ts` | 自然周（周一为起点）与完成率计算 |
| 界面 | `src/App.tsx` + `src/styles.css` | 台账、确认、方案、留档四个标签页 |

说明：完成率与确认判定只针对方案遮盖眼；对侧眼记录仅作矫正视力留档。
